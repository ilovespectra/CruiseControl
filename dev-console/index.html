Prepare a clean branch

Stage the files you intend to commit in your editor first. This commits all staged changes only; unstaged files remain untouched. Commit hooks and signing stay enabled.

Ollama receives the staged diff locally at 127.0.0.1:11434. Review what you staged before confirming. Push your commit to main before repackaging.

Repackage binaries

Build the latest clean, pushed production commit. Version advances automatically using the existing release policy. Builds and logs survive closing this page or restarting the console.

Local builds work for everyone. Only the authenticated official repository owner with admin access can create a GitHub draft. Other accounts produce local previews. Nothing here publishes a release.
